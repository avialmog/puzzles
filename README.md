# Puzzles

A small puzzle game web app: Sudoku, Word Search, and Word Scramble.

- React + TypeScript + Vite, `react-router-dom` (HashRouter)
- CSS Modules, no UI framework
- No backend — progress is tracked in `localStorage`
- Vitest for unit tests of the pure domain logic (puzzle generators/solvers)

## Development

```
npm install
npm run dev
npm run test
npm run build
```
